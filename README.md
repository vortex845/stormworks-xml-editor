# Stormworks XML Editor (WIP)

Десктопное приложение для просмотра и редактирования файлов построек игры Stormworks.

## Возможности

- Открытие и валидация XML-файлов сохранений
- Просмотр структуры постройки
- Редактирование компонентов
- Сохранение изменений обратно в XML
